# Coffer · 凭证管理器 v1

## 用户
- 注册：邮箱 + 设置主密码（解锁凭证）
  - 二次确认主密码
  - 强度提示（至少 8 位，建议 12 位以上）
  - 勾选确认「主密码无法找回」后才允许创建
- 登录 / 解锁：单一主密码（登录=解锁，已确认不做双密码分离）
  - 理由：只记一个秘密，符合"一切从简"；服务器侧认证用 SRP 等不回传密码的方案兜底
  - 改主密码 = 全库重加密
- 查看详情需再次验证
  - 仅主密码（已移除生物识别）
  - 未验证时只显示标题、类型、文件夹、修改时间等元信息
  - 解锁仅对当前条目有效，切换条目重新上锁

## 凭证
- 类型（决定条目的主体表单）
  - 账号：用户名 + 密码 + 网址
  - 卡片证件：卡号 / 证件号 + 有效期 + 密码 PIN（可选）
  - 安全笔记：正文
- 图片是附件，不是类型
  - 任何条目都可挂图片附件（如账号挂实名单截图、卡片挂正反面）
  - 客户端加密后上传，云端只存密文
- 操作
  - 新建 / 编辑 / 删除
  - 搜索（名称 / 用户名 / 卡号 / 备注）
  - 复制（10 秒后清空剪贴板）
- 分类：文件夹

## 加密
- 零知识：主密码派生密钥
- 客户端加密后上传，云端只存密文（不含明文、不含密钥）
- 忘记主密码 = 数据不可恢复（需明示）

## 多端
- Web
- 桌面
- 移动
- 同一套数据模型与加密逻辑

## 不做（留给后续版本）
- 自动锁定 / PIN 快速解锁
- 浏览器扩展 / 自动填充
- 团队共享与权限
- 多因素认证 / Passkey
- 图片 OCR、泄露监控
- 导入导出、审计日志
